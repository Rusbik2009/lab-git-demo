# lab-git-demo

\# Навчальний проєкт з Git та GitHub



Цей репозиторій створено для виконання лабораторної роботи. 



Основні речі, які тут відпрацьовуються:

\* Базові команди Git (commit, push, pull)

\* Робота з гілками (створення, перемикання, merge)

\* Створення Pull Request та форки

\* Робота з Issues та автоматичне закриття задач через коміти
